🚀 QUICK START (Copy & Paste)

Terminal 1 - Backend:
  $ unzip AgriSense_Backend_v2.0.zip
  $ cd backend_final
  $ python -m venv venv
  $ source venv/bin/activate
  $ pip install -r requirements.txt
  $ python main.py
  ✅ http://localhost:8000

Terminal 2 - Frontend:
  $ unzip AgriSense_Frontend_v2.0.zip
  $ cd frontend_final
  $ npm install
  $ npm run dev
  ✅ http://localhost:5173

Open Browser:
  → http://localhost:5173
